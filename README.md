# Nona-me Sales V19 — Clean Build

A clean responsive prototype for iPhone, iPad, Android phone/tablet, Windows and Mac.

## Included
- Single-language UI: Khmer OR English, never both together.
- Light / Dark / Auto appearance.
- Visual color picker; no color-code fields shown to admin.
- Admin Control Center with Overview, Products, Promotions, Stock, Staff, Website Control, Appearance, Reports, Audit Log.
- Staff: Sales, Expenses, Stock, Bank Deposit, Daily Report. Staff has no Weekly/Monthly report menu.
- Products can have images.
- Stock can have images and notes.
- Promotion bundles such as 2 cups for a fixed price.
- Grid/List menu view.
- Daily report compact Telegram copy format with separator lines.
- Print report.
- CSV export suitable for Google Sheets.
- Official Nona-me logo and PWA icon assets.
- Remember Login.
