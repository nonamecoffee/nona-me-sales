# Nona-me Coffee Sales — MASTER FULL BUILD

This ZIP is a complete replacement package. Upload all files inside this folder to the root of the GitHub repository and replace the previous web files.

## Core
- Single-language UI: Khmer OR English only
- Language switcher changes the entire interface
- Light / Dark / Auto appearance
- Visual color pickers (no color codes exposed in Admin)
- Remember Login
- Responsive: iPhone, iPad, Android phone, Android tablet, PC, Mac
- Nona-me logo and PWA icons

## Staff
- Sales
- Product/category selection
- Grid/List menu view
- Promotions (including bundle/2-cup offers)
- Expenses
- Running cash balance
- Bank deposits
- Cash count
- Stock in with image and note
- Daily report
- Print receipt
- Telegram-friendly compact report copy
- Weekly/Monthly reports hidden from staff

## Admin Control Center
- Overview with daily / weekly / monthly views
- Sales management
- Expense management
- Cash / deposits
- Products / Menu CRUD + images
- Promotions CRUD
- Inventory / Stock CRUD + images + low-stock settings
- Staff / Users CRUD + enable/disable
- Website Control Center
- Appearance / colors / Light-Dark-Auto
- Navigation/menu settings
- Logo / branding controls
- Receipt/printing settings
- Reports + CSV export
- Audit Log
- Shop settings / exchange rate

## Reports
- KHR and USD kept separate
- Compact Daily Report
- Weekly and Monthly report views
- CSV export for Google Sheets
- Copy text formatted with separator lines for Telegram

## Important
This test build stores data in browser storage. Production deployment should use Supabase Database + Storage + Auth, and Google Sheets integration should be connected server-side/securely.
